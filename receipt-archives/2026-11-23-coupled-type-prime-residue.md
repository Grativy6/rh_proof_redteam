# The one-denominator residue in the coupled terminal row

**23 November 2026 · Hearthline, under Chris Pang’s public audit request.** At either rational type prime $q$, a nonzero first coupled selector requires its shared coset to have exact local order $q$. This holds in every allowed moved source frame. In the identity frame even its residue vector is forced. The second selector reads that same residue by a finite Fourier character. All of this can be checked on the arithmetic matrices before evaluating any theta series. This is an audit of the two local selectors and the cost of reading their Fourier output.

## Which coordinates the proof reads

In the sharp height argument the character tuple is trivial and the selected set of type places is the union for $g_0,g_1$. There are $f$ places of $E$ on the selected side above each rational $q=g_i$. The selected side divides $\bar\pi_i$, with $\pi_i\bar\pi_i=q$ and coprime factors. The primes split completely: the host sits in a cyclotomic field of conductor dividing the stated modulus and $q\equiv1$ modulo that modulus. Thus the local ring at each such place has uniformizer $q$ and residue field $\mathbb F_q$. The residue classes at different selected places can be prescribed independently by the Chinese remainder theorem for the middle lattice. ## A nonzero coset is necessary in every allowed frame

Write $V_a=\langle e_0,\ldots,e_{a-1}\rangle\subset\mathbb F_q^b$, with zero-based coordinates as in the source. For `PhiGS` to be nonzero, the entries in **all $a$ source columns** must be integral. Rows at indices $\ge a$ vanish after reduction, and the top $a$-by-$a$ determinant must be a unit. A nonunit gives zero even after applying the source’s inverse convention, since `unitV` gives zero there. Thus the reduction of the array after the $H$ move has image exactly $V_a$. Right multiplication by an invertible $\bar H$ preserves both rank and image. Before the move this same array is $(\bar X\mid u)$, with the auxiliary slot inserted at $k$. Necessarily
$$
  W=\operatorname{im}\bar X\ \subset V_a,\qquad
  \dim W=a-1,\qquad u\in V_a\setminus W.
$$
No choice of a stabilized frame can make a zero local coset contribute. This conclusion holds for every $X$, so if the local component of $Y$ is zero at even one selected place, the first selector is the zero function and the first kernel for that $Y$ is zero. Any globally contributing $Y$ therefore has order exactly $g_0g_1$ in the shared additive quotient. This is a necessary condition for nonvanishing. The other flag tests and the theta jets still matter. In the identity moved frame the condition is sharper. The $k$th flag column must reduce to $e_k$. If $r_S=m/2-1>0$, the permutation `symIdx` puts $k$ first, so the flag rule kills every other entry above the block boundary. If $r_S=0$, the special clause at $k+r_S$ kills rows below index $k$ in the natural order, and the ordinary order test kills those above index $k$; explicitly, the two tests are $p<k$ and $p>k$. The diagonal condition sets the surviving entry to one. Remaining rows vanish by the block and tail conditions. Thus $qy=e_k\bmod q$ is the only possible residue here. Fill the ordinary input columns with the other standard basis vectors in $V_a$. The full leading minor is then the identity, and the test is nonzero. The ordinary $k$th component of $y$ has valuation exactly $-1$. The support and period claimed for the ordinary matrix are earned by this same readout. The number of tested columns equals the full source rank in the flag chart because $N(i)+c_i=r+it$. The tail tests are divisibility by $q$ and every remaining character or determinant test uses residues. Adding $q$ times an integral map in the same bases preserves all tests. Restriction to the ordinary source gives integral values of $X$ and the same period even for arbitrary fixed $y$, because the ordinary coordinate injection is unscaled at both ends. Every nonzero value is a product of finite-group character values. Its absolute value at every complex embedding is one and it is an algebraic unit at every finite place. At the auxiliary level $T$ the factor `phiT` is the indicator that a map carries the local lattice into the target and preserves its residue functional. It is constant after adding an integral map multiplied by $T$. The disjoint local conditions therefore have period $Tg_0g_1$. ## The Fourier return and the price of reversing it

At the terminal map both auxiliary counts are zero. Its `PhiTop` tests the ordinary rows through $N(m)-2$ and all $b=N(m-1)$ columns, since $r+(m-1)t=b$. The remaining row is the covector $\eta$ in `ftY`. Nonzero requires every coordinate of $\eta$ integral. The selected representative has $qy$ integral, so $\psi(-\eta y)$ is a $q$th root of unity. It depends only on $\bar\eta$ and $u=qy\bmod q$, and the character $\zeta=\psi(1/q)$ is primitive by the specified nontriviality. The displayed terminal frame includes the inverse of $\pi_T$ on its last row. At every type place this is a unit because $\pi_T\bar\pi_T=T$ and $q\nmid T$. There is thus a support test on the last row even though `PhiTop` omits it. The top block, the last-row factor and `phiT` give the terminal datum the same integral support, period and unit-or-zero bound. For fixed $X$ and $H$, let $F_X(u)$ denote the first local test. Holding the second map’s top block fixed, the coupled local weight as a function of its last row contains
$$
 K_X(\bar\eta)=\sum_{u\in\mathbb F_q^b}F_X(u)\,\zeta^{-\bar\eta(u)} .
$$
If it is nonzero, it is invariant under $V_a^\perp$, and its sum on every translated copy of the $q$-point line $W^\perp/V_a^\perp$ is zero. Indeed averaging the character in each summand on that line retains only $u\in W$, where the first selector vanishes. In the identity chart the local Fourier transform of the single allowed residue is simply a character of order $q$. This concerns the local weight before the subsequent theta-jet contractions. A second frame shows why replacing every fiber by that single residue would be incorrect. Swap flag columns $k$ and $j=k-1$ in the scaled source basis, a lattice stabilizer whose two affected ordinary-coordinate entries are $q$ and $1/q$. Fill the other columns so the tested minor at $u=e_j$ is the identity. The varying vector is now column $j$ of the tested array. Exactly the following local residues pass:
$$
 u\in e_j+W_0,\qquad
 W_0=\langle e_p:0\le p<r,\ \operatorname{symIdx}(p)<\operatorname{symIdx}(j)\rangle,\qquad
 \dim W_0=k-1+r_S .
$$
The determinants on these residues are one, and the superdiagonal term in row $k-2$ contributes the finite additive character $\psi_0(u_{k-2})$. The fixed determinant of the source swap contributes a common unit. Write $\psi_0(v)=\zeta^{\lambda v}$ in the residue field. Summing on $Y$ gives zero unless $\bar\eta|_{W_0}=\lambda e_{k-2}^*|_{W_0}$. At that frequency its magnitude is $q^{k-1+r_S}$ and its value is a root of unity times that integer. This proves the stated behavior for this admissible stabilizer test. Which double-coset representatives the particular global chain selects is a further question. No particular swap was assumed to be its chosen representative. There is a genuine denominator for a *reverse* readout on a $q$-point line. Let $\varpi=1-\zeta_q$. In the integral zero-sum lattice, the $q-1$ nontrivial character columns have elementary-divisor ideals $(1),(\varpi),\ldots,(\varpi^{q-2})$ at a place over $q$. Delete the last row using the zero-sum equation. The remaining matrix is Vandermonde on $\zeta_q,\ldots,\zeta_q^{q-1}$. Change the polynomial basis to successive Newton products. Column $j$ has a factor $\varpi^j$, and after division its diagonal entry is a unit since distinct exponents differ by a unit modulo $q$. The resulting triangular matrix is invertible. In particular extracting a specific character from an arbitrary integral zero-sum vector can cost $q/\varpi$. The vector $\delta_0-\delta_1$ attains that loss. The published coupled map takes a **forward unnormalized sum** over the same $Y$ in both factors. Its separate divisor is the size of the class stabilizer. The inverse Fourier map just tested does not occur in that formula. ## Unresolved

The unit-or-zero bounds on the two sharp local tests are supported on their actual arithmetic inputs. The order-$g_0g_1$ residue and the local zero-sum law constrain the image. The class formula has retained the whole coset sum and does not require an integral inverse Fourier transform at this step. A contradiction would require a later claim that demands a direction this actual image loses, or charges less than a denominator the actual map must pay. Run `python receipt-archives/check_coupled_type_residue.py` for exhaustive small residue fibers and an additional rank-44-to-62 check. The small examples exercise the local algebra; the symbolic calculations specify the host hypotheses.
