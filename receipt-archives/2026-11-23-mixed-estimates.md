## 4. Work

**Section growth.** Give each index the rank-two weight $(1,0)$ and call the resulting divisor $L$. The model dimension is $m$ and its own flag-degree formula gives $L^m=m!$. Each Weyl factor is one. The named release condition requires some real $C$ such that for all positive integers $t$,

$$
\left|\dim_K H^0(Y,tL)-\frac{L^m}{m!}t^m\right| \le C t^{m-1}.
$$

Substitution gives $|1-t^m|\le C t^{m-1}$. Choose an integer $t>|C|+2$. Then $(t-C)t^{m-1}>1$, hence $t^m-1>Ct^{m-1}$. Every choice of $C$ fails. This works for every nonempty finite index set and every number field with the instance required by the builder. The release’s condition quantifies over all $Y$ in the returned geometry, so this single choice of rank suffices for each builder output. [Exact growth condition](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Formalism/SharpRestriction/Divisibility/HeightShare.lean#L299-L304) · [Diagonal degree](https://github.com/leanprover-community/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Formalism/DegreeFormula/FlagDegFormula.lean#L21-L29) · [Proof at the builder’s own type](GeneralFlagGrowth.lean)

With two indices, the familiar surface is $\mathbf P^1\times\mathbf P^1$. The true line bundle $\mathcal O(t,t)$ has $(t+1)^2$ sections for $t\ge0$. The model returns one. A second, independent failure uses the nonzero ruling of bidegree $(1,0)$. Its square is zero, yet the model labels it big. This falsifies the release’s `GloballyGeneratedNef` implication for that example. Both properties occur in the actual definition of `AdmG`. **A mixed flag coefficient that RH reaches.** For one flag with $N=3$ and $j=1$, the release uses two copies of the cut weight $\mu=(0,-1,-1)$ and one varying weight $\nu$. Its mixed degree is $\nu_1-\nu_2$ (zero-based coordinates). For $\nu=(2,1,0)$ the answer is **1**. The diagonal Weyl polynomial at $\mu+t\nu$ is $3t+9t^2+6t^3$. Its linear coefficient is three times the mixed degree. We also evaluated the alternating polynomial coefficients directly over the integers. Calling the first-slot model on the same three weights would give **0** with $\mu$ first and **6** with $\nu$ first. The code actually takes the polynomial coefficient, and uses that identity in a positivity proof. Take $d=1$, $A=N=(1,1)$, $b=q$, $c=1$, $M=2A$, and $L=2qA$ on the projective surface over $\mathbb Q$. The ampleness and nefness hypotheses hold, the degree of $A$ is positive and every nef bidegree has nonnegative intersection with $A$. The theorem’s strict numerical premise is $4(A\cdot M)<q$. The correct left side is **16**. The substitute would give **8**. At $q=9$ the substitute would admit an input which fails this premise. At $q=16$ equality still fails the strict test. At $q=17$ all premises hold, and the actual conclusion evaluates to **$272<2312$**. The rejected $q=9$ input is a counterexample to interchanging the two operations at the premise.
