Read the rule

With m = 2 to the chosen number of bits, every whole number x has a unique split x = carry × m + remainder, with 0 ≤ remainder < m. Keeping only the remainder can merge different original numbers.

The squaring view uses ordinary BigInt arithmetic. The saved Lean and Python runs document the separate implementation checks. On the original released prime example, the full 385-bit value is prime and its low 64 bits are divisible by 3.
