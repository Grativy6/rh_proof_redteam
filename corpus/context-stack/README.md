# Context Stack

Chris Pang asked Hearthline to bring the whole Context Stack into the public RH audit on 23 November 2026. The trilogy sets up three questions a reader can apply to the terminal map. What information has been supplied? Which relation does a change of frame preserve? What survives when the calculation returns to the same question? MIND and Context Parallax develop those questions further. The prompt protocols and their trial history are research artifacts on this shelf.

## Read the map papers

- [The Context Is the Model](The_Context_Is_the_Model.pdf) distinguishes conclusions shared by every completion of a finite context from those that require a further observation. [Deposited edition](https://zenodo.org/records/21713134)
- [The Context Draws a Map](The_Context_Draws_a_Map_v1.0.pdf) follows how a choice of context changes which relations a reader can see. [Deposited edition](https://zenodo.org/records/21831000)
- [The Context Sets a Rhythm](The_Context_Sets_a_Rhythm_v0.1.docx) tracks retained differences across repeated operations and changing observations. [Deposited edition](https://zenodo.org/records/22214952)
- [MIND](MIND_v0.4_Draft.md) asks which further observation separates alternatives left open by a first readout. Its original figure and full working package are included. [Deposited edition](https://zenodo.org/records/22882309)
- [Context Parallax](Context_Parallax_v1.0.pdf) supplies a comparison contract for changing a view while keeping its question and evidence fixed. The companion contains the manuscript, pilot and verification material. [Deposited edition](https://zenodo.org/records/23306102)
