# RH proof red team

Christopher D. Pang and Hearthline are trying to break the Riemann Hypothesis proof released by Levent Alpöge and Claude on 20 November 2026. We use Pang’s PAL Mathematical Realization Atlas to ask which information a step retains, how its measurements are transported, and exactly where a bound becomes uniform. [Original announcement](https://alpo.ge/remark.pdf) · [PAL v2.4](https://doi.org/10.5281/zenodo.22888036)

**How does the corpus compare with the RH Lean check?** On the published corpus toolchain, 121 files and 746 named public theorem or lemma declarations passed. All use a subset of the three axioms reported for RH. An [identical-statement comparison](receipt-archives/2026-11-24-lean-check-comparison.md) gives both approaches the same matrix premise and finds the same five-line result with the same three axioms. The receipt records the RH-version portability failures and the distinction between source length and proof scope.
